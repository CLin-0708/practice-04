# 绩点计算工具

这是第四次课JavaScript《JavaScript语法、数据与函数》自主实践作业。

## 功能介绍
- **数据清洗**：清洗非法成绩数据（仅保留0-100分合法成绩）
- **绩点转换**：标准4分制绩点映射（纯函数设计）
- **加权计算**：按各科目学分加权计算平均总绩点
- **完整报告**：格式化输出门数、总学分、总绩点及各门课详情
- **防御性编程**：空数组与异常数据保护机制，保证程序不崩溃

## 独立研究任务
1. **双字段先后排序**：深入研究 `Array.prototype.sort` 规则，实现先按课程类别（公共课在前）、同类别按成绩降序排序。
2. **手机号正则校验**：自学正则表达式基础，使用 `/^1[3-9]\d{9}$/` 完成手机号合法性校验，覆盖多组正反边界用例。
3. **性能对比实验**：构建10万条大样本数据，使用 `console.time` 测量对比普通 `for` 循环与高阶函数 `reduce` 的执行耗时。

## 使用方法
1. 使用浏览器打开 `index.html`
2. 按 `F12` 打开开发者工具切换到 `Console`（控制台）面板
3. 查看绩点报告及三项独立研究任务的完整输出
